# Linkgurus decision-head icons

Six editorial icons for decision-method content, workshop materials, social posts, and diagnostic cards.

- `framing` — define the decision before solving it.
- `synthesis` — convert multiple inputs into one usable view.
- `decision` — make and record a choice.
- `alignment` — bring stakeholders to one decision point.
- `enactment` — move the choice into an operating state.
- `accountability` — assign and maintain a named owner.

These are intentionally separate from the core UI sprite until brand approval. Use at 32 px or larger; do not use as the corporate hero mark.

# Linkgurus portfolio icon families

Each numbered family is self-contained:

- `stream/` — the parent portfolio-stream icon.
- `offers/` — Entry, Flagship, and Scale offer icons.
- `previews/` — editable SVG and rendered PNG review boards.
- `linkgurus-icon-library-*.svg` — a four-symbol family sprite.

The root `linkgurus-icon-library.svg` remains the complete shared sprite.
